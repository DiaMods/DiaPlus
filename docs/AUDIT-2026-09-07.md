## Media and dictation

Media handling preserves attachments inside native tool results as well as user messages. Private staging, bounded downloads and cleanup prevent arbitrary path reads and persistent temporary media. Provider adapters translate only supported input channels and surface incompatible media errors.

The native 86584 dictation contract is:

```http
POST /ai-service-local-v1/audio-transcription?stream=1
Content-Type: audio/m4a

<raw audio bytes>
```

The bridge returns `Content-Type: text/event-stream`, with `event: text_response` and JSON `data: {"delta":"..."}` records; EOF completes the request. The legacy response is `{"text":"..."}`. The native URL builder was invoked live and the request/event layout was traced in the executable. A Swift URLSession client also sent a synthetic AAC/M4A phrase through the complete isolated bridge: native SSE/EOF and legacy JSON both returned “Media fixture test.” A foreign Origin was rejected. This does not establish microphone capture or native permission-flow behavior.

Apple defaults to local Vision observations for images because the installed macOS 27 beta's native attachment generation can be guardrailed. Explicit native-image mode remains available. Apple's managed PCC entitlement is still required for Private Cloud Compute.

## Connectors and local workflows

Connection state, credentials, schema caches and imported/indexed records are isolated by Dia profile. MCP initializes and negotiates sessions, handles pagination and bounded JSON/SSE or stdio responses, and does not replay a possibly completed write. Disconnect/configuration changes invalidate in-flight work. Local subprocess adapters use fixed arguments, limited environments, bounded output and timeouts without a shell.

OAuth supports protected-resource/server discovery and advertised public-client registration, with manually registered client IDs as a fallback. Generic incremental sync only accepts a read-only tool and advances its cursor after indexing succeeds. These are extension points, not fabricated service-specific account sync. See [Connectors](CONNECTORS.md).

Spark 1.3.1 adds attachment access, drafts, triage, assignment, sending/scheduling, comments and event changes to the existing read catalog. Spark account permissions still apply. Real write operations were not performed during testing.

Knowledge stores retain source URLs and research provenance. Research jobs use read-only tools and save results to the current profile's library. Schedules default off, require explicit enablement, avoid overlap and skip missed intervals after restart. Native browser actions and connector writes are unavailable in that runner. See [Local workflows](LOCAL-WORKFLOWS.md).

## Update behavior

`custom-updater` is optional and **enabled by default**; required `update-blocker` continues to disable stock Sparkle replacement. Native update controls open the custom update surface. Background checks announce available official releases; download/preparation and installation are explicit actions.

Preparation verifies the pinned publisher, signed archive, extracted app identity/version and every configured Mod before building with the bundled toolkit. In-app preparation stops on any incompatible enabled Mod and never silently disables one. It does not require the development checkout, but Apple build tools and signing configuration must be available. No remote Mods repository is configured; that work is deferred.

Installation links the previous app with a complete profile snapshot, preflights a disposable profile and checks launch health. Signed preparation, active installation and the final same-build refresh passed; a paired rollback transaction was retained. The two-launch preflight preserved extensions, open sessions and pinned-tab data. The earlier failed preflight prevented the candidate from reaching the live profile. Failed-install restoration was tested with fixtures, not by deliberately failing and restoring the user's installation.
